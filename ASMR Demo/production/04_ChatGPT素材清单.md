# 给 ChatGPT 画的素材清单

目的：让网页 demo 里的角色**完全按原画设计**动起来（眨眼、口型、表情、动作切换）。做法是"同一构图的多张差分图"按时间切换，这和 Live2D/视觉小说立绘的原理一样。

## 通用规则（每次对话开头先发一次）

1. 先上传 `ASMR Demo/Character.jpg`，然后发：

> 这是我的原创角色设定图（上：小雪，雪女；下：小焰，狐火精灵）。接下来请严格按照这张设定图画图：发型、发色、发饰、狐耳、服装、配色、Q版比例和画风都必须一致。日系动画赛璐璐上色，线稿干净。**透明背景 PNG**，尺寸 1024×1536（竖图），角色居中，头顶、耳朵和发饰完整，不要被裁切。不要画文字、特效、阴影背景。

2. **差分图一定要用"编辑上一张图"的方式生成**（点开刚生成的图 → 编辑/在此基础上修改），并且每次都加这句：

> 保持这张图的构图、姿势、角色大小和位置、光影完全不变，只修改脸部表情：……

3. 如果无法透明背景，就用**纯绿色 #00FF00** 纯色背景，我来抠。
4. 文件名按下表命名，全部放进 `ASMR Demo/art/` 文件夹（没有就新建），然后告诉我。
