# Demo 5《四季暴走列車 / The Runaway Seasons Express》— 给 ChatGPT 的素材生成命令

一辆魔法列车穿过不断变化的季节。观众坐在车厢里第一人称朝前看。**车厢永远不变，变的是左右两扇窗外的世界**（左窗和右窗可以是不同季节）。没有角色、没有台词。

我会把素材分层合成动画：车厢固定在前景；窗外的景色在窗户遮罩后面横向滚动（视差）；霜花、雨滴、热浪、花瓣等效果叠在玻璃和车厢里。所以素材必须**分开生成、构图一致**。

生成好的图按下表的文件夹放进 `Demo_SeasonsExpress/assets/` 下，然后告诉我。

## 第 2 优先：窗外景色分层（每个季节 3 层，可横向无缝衔接）

窗外景色会**横向滚动**，所以每层都要求：**1536×1024，左右边缘能无缝衔接（seamless horizontal tiling）**，从火车侧窗看出去的平视角度。

- `*_far.png`：远景，天空 + 远山/远处地平线，**不透明**
- `*_mid.png`：中景，透明背景 PNG，画面下半部分画树林/海岸线等，上半部分透明
- `*_near.png`：近景，透明背景 PNG，只在画面最下方画快速掠过的近处物体（灌木、栏杆、草丛等），其余透明
