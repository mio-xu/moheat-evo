# 展示模式（Kiosk）· 工作人员设置说明

一台电脑、一副 MoHeat Evo，在展会 / 店面里一位接一位地给访客体验。全部要求和验收清单：[`docs/kiosk/REQUIREMENTS.md`](kiosk/REQUIREMENTS.md)；A4 速查卡：[`docs/kiosk_staff_card.md`](kiosk_staff_card.md)；设计规则：`DEMO_DESIGN_GUIDE.md` §7.4「展示模式」。

## 1. 网址

| 用途 | 网址 |
|---|---|
| 展示模式（屏幕 1，访客用） | `https://moheat-evo.github.io/kiosk/?kiosk=1`（打开一次后，这台浏览器一直是展示模式，直到在面板里退出） |
| 排队屏（屏幕 2，面向排队的人） | 工作人员面板 →「Open queue screen」（或直接打开 `…/kiosk/queue.html`） |
| 排队时手机选 Demo | 屏幕上 / 海报上的二维码 → `…/kiosk/pick.html?o=…`（不用服务器，号码和展示机一致） |
| 打印排队海报（A4） | 面板 →「Print QR poster」（`…/kiosk/poster.html`） |
| 不在展示模式时的 30 秒冷热入门 | `…/kiosk/intro.html` |

## 2. 开展前（每天一次）

1. **电脑不要睡眠**：macOS「系统设置 → 锁定屏幕 / 显示器」都设为「永不」，或在终端运行 `caffeinate -dis &`；Windows「电源 → 屏幕和睡眠 = 从不」。页面本身也会请求「屏幕常亮」（Wake Lock），但系统设置更可靠。关掉系统通知 / 自动更新。
2. 用 **Chrome 或 Edge**（需要 Web Serial）。推荐全屏应用模式：
   `open -a "Google Chrome" --args --kiosk --autoplay-policy=no-user-gesture-required "https://moheat-evo.github.io/kiosk/?kiosk=1"`
   （Windows：`chrome.exe --kiosk --autoplay-policy=no-user-gesture-required https://…/kiosk/?kiosk=1`）。不用命令行也可以：打开网址后按 F11 / ⌃⌘F，或面板里的「Fullscreen」。
3. 插上 MoHeat Evo（USB 或蓝牙配对好），在**左上角连点 5 次** → 输入 PIN（第一次是 `0000`，请马上在面板里改成自己的 4–8 位数字）→ 面板「Device」里点 **+ Add** 选择设备 → Connect。授权一次后，每个页面都会自动连接，右上角小圆点变绿。
4. 面板里设好：默认语言、**强度上限**（默认 80 %）、新访客起始强度（默认 50 %）、空闲重置时间（默认 60 秒）、精华版 / 完整版（默认精华版 60–90 秒）、开放哪些 Demo、价格区间和币种、卫生标识、（可选）产品消息表单的网址。设置只保存在这台浏览器里。
5. （可选）提前缓存：面板「Save all demos for offline」，进度到 100 % 后断网也能跑。
6. 关掉面板，自己从欢迎画面走一遍：引导 → 选一个 Demo → 体验卡。

## 3. 两块屏幕（一台电脑）

- 屏幕 1 = 访客的屏幕：欢迎 → 30 秒引导 → Demo → 体验卡，角落一个小二维码。
- 屏幕 2 = 排队屏：面板里点 **Open queue screen**，把弹出的窗口拖到第二块显示器上，在窗口里按 **F**（或双击）全屏。排队屏显示：大的「扫码先选」二维码、访客此刻的画面（能镜像时）和字幕、**两只耳朵的冷热大图**（暖 = 橙色 + 热气，凉 = 蓝色 + 雪花）、正在体验的 Demo 和号码、推荐的 3 个；没人时轮播封面。两个窗口在同一台电脑、同一个浏览器里，自动同步（BroadcastChannel），不需要网络。
- macOS：「系统设置 → 显示器 → 排列」选「扩展」，不要「镜像」。

## 4. 访客流程（全自动）

欢迎画面（选语言、三步图示、推荐的 3 个、全部号码）→ 2 秒片头（标志 + 冷→暖扫过两耳，同时确认设备）→ 30 秒引导（戴耳机 L/R → 音量 → 左暖 → 右凉 → 冷热快速切换 → 同耳冷热 → 强度：弱一点 / 刚好 / 强一点；随时可跳过；**不靠声音也看得懂**）→ Demo（默认互动、可切换纯享；默认精华版约 80 秒；右下「✕ 结束」和大音量滑块）→ 体验卡（一屏一题，点了就下一题，约 10 秒；15 秒没人操作自动关闭）→ 回到欢迎画面，上一位的语言 / 强度 / 模式全部清空，冷热停止。欢迎画面 60 秒没人 → 轮播（冷热关闭），点一下回到欢迎画面。

## 5. 统计和导出

- 面板「Statistics」：今天 / 累计 的访客数、播放次数、**体验最多的 Demo** 排名、纯享 / 互动、平均星数、最喜欢的瞬间、购买意愿、价位、使用场景、最近的留言。
- **Export CSV**（每天 × 每个 Demo 一行，后面附 购买意愿 × 价位、场景 × 购买意愿 两个交叉表）、**Comments CSV**、**Export JSON**（全部原始计数）、**Daily report**（当天小结，可打印 / 存 PDF）。
- 数据只存在这台电脑的这个浏览器里（localStorage），不发送到任何地方，不含个人信息。换电脑 / 清浏览器数据前请先导出。「Clear stats…」会删除全部计数。

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| 没有声音 | 看访客页上的音量滑块；系统音量；耳机是否被选为输出设备 |
| 不冷不热 | 右上角小圆点是否绿色；面板 Device → Connect；强度上限是否太低；屏幕上的「设备已断开」提示 |
| 画面卡住 | 左上角 5 次 + PIN → Close（会重置到欢迎画面）；还不行就刷新（⌘R / F5） |
| 想换 PIN / 退出展示模式 | 面板 → New PIN / Exit kiosk mode |
