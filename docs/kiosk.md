# 展示模式（Kiosk）· 工作人员设置说明

一台电脑、一副 MoHeat Evo，在展会 / 店面里一位接一位地给访客体验。全部要求和验收清单：[`docs/kiosk/REQUIREMENTS.md`](kiosk/REQUIREMENTS.md)；A4 速查卡：[`docs/kiosk_staff_card.md`](kiosk_staff_card.md)；设计规则：`DEMO_DESIGN_GUIDE.md` §7.4「展示模式」。

**真机检查（自己戴上设备 / 拿手机走一遍，可打印）**：[冷热（约 15 分钟）](qa/real_device_thermal.md) · [手机（约 10–15 分钟）](qa/real_device_phone.md) · [A4 打印版](qa/real_device_checklists.html)。

## 2. 开展前（每天一次）

1. **电脑不要睡眠**：macOS「系统设置 → 锁定屏幕 / 显示器」都设为「永不」，或在终端运行 `caffeinate -dis &`；Windows「电源 → 屏幕和睡眠 = 从不」。页面本身也会请求「屏幕常亮」（Wake Lock），但系统设置更可靠。关掉系统通知 / 自动更新。
2. 用 **Chrome 或 Edge**（需要 Web Serial）。推荐全屏应用模式：
   `open -a "Google Chrome" --args --kiosk --autoplay-policy=no-user-gesture-required "https://moheat-evo.github.io/kiosk/?kiosk=1"`
   （Windows：`chrome.exe --kiosk --autoplay-policy=no-user-gesture-required https://…/kiosk/?kiosk=1`）。不用命令行也可以：打开网址后按 F11 / ⌃⌘F（面板里的「Fullscreen」按钮一进 Demo 页就会退出全屏，只适合临时用）。
3. 插上 MoHeat Evo（USB 或蓝牙配对好），在**左上角连点 5 次** → 输入 PIN（第一次是 `0000`，请马上在面板里改成自己的 4–8 位数字）→ 面板「Device」里点 **+ Add** 选择设备 → Connect。授权一次后，每个页面都会自动连接，右上角小圆点变绿。
4. 面板里设好：默认语言、**暖 / 凉各自的上限**（默认 80 %，也可以点「Calibrate on me」用同样的自动校准在自己身上测一次来设）和起始强度（默认 50 %）、**排队开关**（默认有人排队）、空闲重置时间（默认 60 秒）、完整版 / 精华版（默认完整版：每人一个完整 Demo）、开放哪些 Demo、价格区间和币种、卫生标识、（可选）产品消息表单的网址。设置只保存在这台浏览器里。
5. （可选）提前缓存：面板「Save all demos for offline」，进度到 100 % 后断网也能跑。
6. 关掉面板，自己从欢迎画面走一遍：引导 → 选一个 Demo → 体验卡。

## 3. 两块屏幕（一台电脑）

- 屏幕 1 = 访客的屏幕：欢迎 → 引导 → Demo → 结束流程 → 体验卡，角落一个小二维码。
- 屏幕 2 = 排队屏：面板里点 **Open queue screen**，把弹出的窗口拖到第二块显示器上，在窗口里按 **F**（或双击）全屏。两个窗口在同一台电脑、同一个浏览器里自动同步（BroadcastChannel），不需要网络。macOS「系统设置 → 显示器 → 排列」选「扩展」，不要「镜像」。
- 排队屏有两种画面，面板「Queue screen」里选（宣传视频 / 实时画面 / 每 N 分钟轮换）：
  - **宣传视频**（默认）：全屏循环播放，默认静音（可开声音），角落一直叠着「排队时扫码选 Demo」二维码（三语轮换，大小 / 位置可选），可选「正在体验：号码 · 标题」小标签。视频来源：留空 = `kiosk/media/promo.mp4`（有就用）；或填一个网址；或「…or a local file」选本机文件（存在这台电脑的浏览器里，不进 git）。宣传片本身（EN + JA 双行字幕直接烧进画面）等 Demo 都做好后再制作（TASKS #50 ③）。**没有视频时自动退回实时画面。**
  - **实时画面**：大二维码、访客画面的镜像（舞台是 canvas / video 时）+ 字幕、**两只耳朵的冷热大图**（暖 = 橙色 + 热气，凉 = 蓝色 + 雪花）、正在体验的 Demo 和号码、推荐 3 个；没人时轮播封面。

## 4. 访客流程

1. **欢迎画面**：选语言，推荐 3 个 + 全部号码（排队时扫码选好的人直接点号码），可选卫生标识。
2. **引导**（约 1–2 分钟，访客戴降噪入耳式耳机，所有画面不靠声音也看得懂；「跳过」随时可用）：
   - 戴上**降噪入耳式耳机**（L / R）→ 左右测试：焰从左边说话、小雪从右边说话（访客的语言，声音从远处移到耳边），「是左边吗？」是 / 不是（不是 → 提示把左右耳机换过来）→ 音量滑块（小雪的声音循环）。
   - **「声音没问题的话，请告诉工作人员 👋」→ 工作人员点「继续（工作人员）」**（访客点「有问题」会显示给工作人员的检查提示）。
   - **工作人员把大的 MoHeat Evo 头戴设备戴在入耳式耳机外面**（声音来自入耳式耳机，冷热来自 MoHeat Evo）→ 点「继续」→ 输出确认：左暖 → 右暖 → 左凉 → 右凉，各约 2 秒，画面上对应的耳朵亮起。设备没连上时屏幕上有大字提示。
   - **「两边冷热都感觉到了的话，请告诉工作人员 👋」→ 工作人员点「继续」**。
   - 暖、凉**自动校准**：左耳慢慢变热（约 7 秒到上限），「快要不舒服时点 STOP」，点的那一刻立刻停止，记为个人上限，之后用 80 %；凉同样（右耳）。没人点就停在工作人员设的上限。
   - 焰（暖）/ 小雪（凉）在耳边说话的试听，冷热跟着她的声音；「自然吗？」太弱 / 刚好 / 太强（±15 %，可重听）。
3. **Demo**：每位访客体验**一个完整的 Demo**（从开头到结尾，再进入结束流程）；默认互动、可切换纯享；右下「✕ 结束」和大音量滑块。精华版（60–90 秒）只是面板里的选项（Experience → Show cut，默认关）。
4. **结束**：
   - **没人排队**（工作人员关掉排队开关）而且没超过面板里的「最多几个 Demo / 最长分钟」：画面问「还想体验别的故事吗？」，推荐 3 个 + 全部 + 「结束」；继续体验不用重新引导和校准。
   - **有人排队**（展会默认）或点了「结束」：冷热先停止 →「请先取下 MoHeat Evo 头戴设备」（工作人员点继续）→「再取下入耳式耳机」→ 体验卡（一屏一题，点了就下一题，15 秒没人操作自动关闭）→ 感谢 + 带走的二维码（约 9 秒，点一下也可以）→ 重置给下一位（语言、强度、校准、模式全部回到默认，冷热停止）。
   - **排队开关**：屏幕左下角的小圆点（橙 = 有人排队，灰 = 没人）**长按约 1 秒**切换，或按键盘 **Q**；不用 PIN，一直保持到下次切换；面板里也可以改。
   - **在场 / 无人开关**（现场标识，REQUIREMENTS §12）：左下角**第二个小圆点**（绿 = 工作人员在场，红 = 无人）**长按约 1 秒**，或按键盘 **S**；面板里也可以改（Staff at the booth）。离开展台时切成「无人」：访客屏整屏「请勿触摸 · 工作人员马上回来」、冷热停止、点按无效；排队屏的标识同步变成「请勿触摸」。回来后再按一次回到欢迎画面。
5. 欢迎画面 60 秒没人 → 轮播（冷热关闭），点一下回到欢迎画面。

## 4b. 现场标识（可以触摸 / 请勿触摸 / 可以拍照）

- 访客屏欢迎画面角落、空闲轮播、排队屏（二维码旁边）都显示：在场时「欢迎体验 ✋」、无人时「请勿触摸 🚫」，以及「可以拍照 📷」。
- 面板「Signs」：触摸标识开关；拍照标识（可以拍照 / 场地禁止时选「请勿拍照」/ 隐藏）；在哪几处显示；访客屏角标的位置。
- 打印立牌：面板 **Print signs (A4 / A5)**（`…/kiosk/sign.html`）→ 选 A4 或 A5 → 打印两页（在场 / 无人），三语。拍照标识跟着面板设置。

## 5. 统计和导出

- 面板「Statistics」：今天 / 累计 的访客数、播放次数、**体验最多的 Demo** 排名、纯享 / 互动、平均星数、最喜欢的瞬间、购买意愿、价位、使用场景、个人冷热上限的平均值（和到上限没点的人数）、最近的留言。CSV 里还有每位访客的暖 / 凉个人上限和试听「自然吗」的回答。
- **Export CSV**（每天 × 每个 Demo 一行，后面附 购买意愿 × 价位、场景 × 购买意愿 两个交叉表）、**Comments CSV**、**Export JSON**（全部原始计数）、**Daily report**（当天小结，可打印 / 存 PDF）。
- 在场 / 无人的时段：面板统计里「staffed / unattended」（时:分），CSV 末尾附时段表，JSON 里是 `presence`。
- 数据只存在这台电脑的这个浏览器里（localStorage），不发送到任何地方，不含个人信息。换电脑 / 清浏览器数据前请先导出。「Clear stats…」会删除全部计数。

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| 没有声音 | 看访客页上的音量滑块；系统音量；降噪入耳式耳机是否被选为输出设备 |
| 不冷不热 | 右上角小圆点是否绿色；面板 Device → Connect；强度上限是否太低；屏幕上的「设备已断开」提示 |
| 画面卡住 | 左上角 5 次 + PIN → Close（会重置到欢迎画面）；还不行就刷新（⌘R / F5） |
| 想换 PIN / 退出展示模式 | 面板 → New PIN / Exit kiosk mode |
