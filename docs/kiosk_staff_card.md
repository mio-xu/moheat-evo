# MoHeat Evo 展示速查卡（A4 一页，打印放在展台）

**网址**　`https://moheat-evo.github.io/kiosk/?kiosk=1`　　**面板**　左上角连点 5 次 → PIN（初始 `0000`，请改）

## 开机（5 分钟）
1. 电脑接电源；**关掉睡眠 / 屏保 / 通知**（macOS 终端：`caffeinate -dis &`）。
2. 插上 MoHeat Evo；打开 Chrome → 上面的网址 → 全屏（F11 / ⌃⌘F，或面板「Fullscreen」）。
3. 面板 → Device「+ Add」选设备 → Connect，右上角小圆点变绿。
4. 第二块屏：面板「Open queue screen」→ 窗口拖到第二块显示器 → 按 F 全屏（默认放宣传视频 + 二维码，没有视频时显示实时冷热画面）。
5. 自己走一遍：Start → 引导 → 选 1 个 Demo → 体验卡。

## 每位访客
1. 访客在欢迎画面点 Start（或排队时扫码选好的**号码**）。先戴**降噪耳机**（L 左 R 右），做左右 + 音量测试。
2. 屏幕显示「声音没问题？请告诉工作人员 👋」→ 确认后点 **继续（工作人员）**。
3. **给访客戴上 MoHeat Evo 冷热耳件** → 点继续 → 左暖 / 右暖 / 左凉 / 右凉 各 2 秒 → 「两边都感觉到了？」→ 点 **继续**。
4. 访客自己做暖 / 凉自动校准（快要不舒服时点 STOP）和焰 / 小雪试听，然后体验 Demo。
5. 结束：冷热自动停止 →「请先摘下 MoHeat Evo」→ 帮忙摘下后点 **继续** → 访客摘下耳机 → 体验卡（约 10 秒）→ 感谢 + 二维码 → 自动回到欢迎画面。
- **排队开关**：左下角小圆点**长按 1 秒**或按 **Q**（橙 = 有人排队：每人 1 个 Demo；灰 = 没人：可以继续体验）。
- 卫生：每位访客后擦拭耳机和耳件；有一次性耳罩套时打开面板「Hygiene badge」。

## 常见问题
| 现象 | 先这样 |
|---|---|
| 没声音 | 页面右上的音量滑块 → 系统音量 → 输出设备是不是耳机 |
| 输出确认时没感觉 | 耳件贴住皮肤了吗？→ 右上角小圆点是否绿色 → 面板 Connect → 点「有问题」→「再检查一次」 |
| 不冷不热 | 小圆点绿了吗？→ 面板 Connect → 强度上限是否太低 → 屏幕上是否有「设备断开 / 电量低」大提示 |
| 画面卡住 | 面板 → Close（重置）；还不行就刷新（⌘R / F5） |
| 太热 / 太凉 | 访客页上调强度；面板「Intensity cap」降低上限 |
| 没网 | 事先在面板「Save all demos for offline」保存过就能继续 |

## 收展
面板 → **Daily report**（当天小结）+ **Export CSV / JSON** 保存到 U 盘。数据只在这台电脑里，不会上传。最后一天收展：Exit kiosk mode。
