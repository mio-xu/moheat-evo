## 用户回答后的修订 · 2026-11-08

> 用户 2026-11-08 回答了两个问题：
> - **"东方古代" = 不点明的架空东方**：不写明唐朝、不贴"武侠"标签、不是平安 / 战国日本；一个自创的东方国度，地名自己起，中日各种意象可以自由混搭（服装不照搬某个朝代：不用幞头、胡服、十二单、狩衣这种一看就定年代的东西）。

### 0.4 冷热（DUAL）共用规则

- 人声层：`(0.1 + 0.8 × 响度)` × 距离（贴耳 1 / ≤ 50 cm 0.6 / 更远 0.28，正前方 × 0.5）——**所有人的声音都是暖的**，除非用户批准某个角色"特殊设定"（雪の斎王、吸血鬼：见各方案，作为问题列在最后）。
- 环境层只用真实存在的冷热源：火、炉、蒸汽、热饮、火把、风、雪、冰、冷水、金属、斗篷 / 披风挡风。
- **魔法只在有真实冷热源时才出温度**：冰魔法 = 真的冰晶飞在耳边（冷）；火魔法 / 龙息 = 真的火焰点燃了什么（热，而且有距离）；光、结界、召唤阵的光 = **不出温度**（只有声音和画面）。
- 每个 Demo 至少一次：同一只耳朵同时冷 + 热、一个**移动的**冷热源（绕头、从左扫到右）、左右耳不同。

### 0.6 最大的风险：大换装后脸还是不是同一个人

用户已经指出过"近景远景必须是同一个人"。换衣服、换发型、加角 / 精灵耳，模型很容易把脸一起改掉。锁脸方法（按便宜到贵）：

1. **参考图**：Image 1 = 角色现有立绘基准的原图（`assets/art/` 里的 PNG），Image 2 = 脸部放大裁切；提示词里写死不变项（眼型、眼色、发色 hex、泪痣 / 虎牙位置、画风），只写"改衣服、改发型、改身份道具"。
2. **先出"锁脸设定图"**（头肩，正面 + 新发型），用户确认后，所有姿势都以它为参考。
3. **遮罩编辑反过来用**：现在 `tools/openai/images.py --mask` 是"只有椭圆可以改"。需要加一个小选项 `--keep "cx,cy,rx,ry"`（椭圆**以外**可以改、脸保持像素不变），换衣服时把脸锁死；换发型时椭圆只盖眉眼鼻嘴，不盖发际线。
4. **画风统一**：男性向用直播系列的柔和赛璐璐（深薰衣草线、无光泽），女性向用 3 号柔和赛璐璐；东方古代**不用**信長系列的浮世绘金箔风（避免像另一个系列）。
5. **检查**：每张姿势和原角色并排拼图（`assets/poses_preview.jpg` 加一列"原版脸"），逐项比对眼型 / 眼色 / 发色 / 锚点；发色用取色比对 hex。不像就只重画那一张。

其他共用风险：
- 第一次做"三个人、四个场地"的 Demo，素材量比之前多约 1/3（之前单人约 25 张）。控制方法：每人只做 2 个姿势；第 5 段三人同框用各自的立绘层拼，不另画群像。
- 发型变化遮住脸（帽子、面纱、面具）会坏掉嘴部补丁 → 面纱只到下巴下、面具推到头侧、帽檐不过眉。
- 非人种族特征（角、精灵耳、狐耳、翅膀）会改动脸的轮廓 → 角 / 耳只在设定图阶段加，之后的姿势都从设定图编辑。
