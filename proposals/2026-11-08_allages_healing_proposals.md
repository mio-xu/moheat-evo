## 1. 全年龄小游戏 A（动作 / 反应）

画风：全年龄系列（可爱日系 2D、粉彩赛璐璐、2–3 头身大眼，§5.1）。小游戏都要有**明确的胜负反馈**（星级 / 心数 / 失败重来），但对小孩友好：失败只退回本关开头，不会 Game Over。

### A1 ふわふわききゅう、くものうえへ！ · Up, Up and Away! · 热气球，飞上云端！

- **设定**：黎明的草原，你和狐狸向导 **コハク**（Demo10 的角色，声音和造型都已有）坐上一只小热气球，要飞到云上的灯笼祭典。
- **新在哪里**：第一个**天空 / 上下方向**的 Demo。Demo04 列车是被动看，这里是自己驾驶。玩法照搬真实热气球：**热气球不能转向，只能换高度，找到往目的地吹的那层风**——小孩也能学到一点知识。
- **5 段（约 2:30）**
  1. **起飞**（草原黎明）：按住 🔥 燃烧器，气球慢慢升起。教学：按得越久越热、升得越快。
  2. **三层风**：每层风从不同方向吹来（声音 + 凉风在那一侧）。コハク问「風はどっちから？」→ 你回答左 / 右，再升到往东吹的那一层；途中用钩子钩 3 面星星旗。
  3. **雷云谷**：上面是雷云（太高 = 冷雾、两耳凉），下面是树梢；在中间穿过去。碰到雷云 → 气球一震，回到本段开头。
  4. **火山岛的上升气流**：右边火山的热气把你托起来（右耳暖）。关掉燃烧器省燃料；高空的冷风从左边来 = 左凉右暖同时。
  5. **降落**：慢慢放气，落在祭典的着陆圈里（按住 / 放开控制）；按落点、燃料、星星旗给 ★1–3。コハク在耳边小声：「またいっしょに飛ぼうね」。
- **互动（7）**：按住燃烧器（主操作）· 二选一「左から / 右から」（能说，按含义判定）· 点上 / 下切换风层 · 点星星旗 · 说「上がれ！」/「止まれ！」也能控制燃烧器（语音指令）· 降落时按住 / 放开 · 结尾二选一（「楽しかった！」/「もう一回！」）。
- **冷热（DUAL）**

  | 来源 | 位置 | 类型 |
  |---|---|---|
  | 燃烧器（头顶约 1.5 m，真实热气球的辐射热很强） | 两耳，按住越久越强，最高 0.9；**6 s 后自动降档**（安全） | 暖 |
  | 各层的风 | 迎风那只耳，阵风脉冲 | 凉 |
  | 高空冷雾 / 雷云边缘 | 两耳 | 凉 |
  | 火山上升气流 | 右耳 | 暖 |
  | コハク的声音 | 坐在你左 / 右边说话，贴耳时最强 | 暖 |

  展示点：点按燃烧器 + 阵风 = 同一只耳 1 s 内冷热切换；按住到顶 = 强度最大；火山段左凉右暖 = 方向；燃烧器 + 侧风 = 同耳冷热同时。
- **声音**：コハク（ElevenLabs，已登记 `kohaku`，免试听）约 18 句；燃烧器、风、雷、祭典音乐都程序合成。
- **画面分层**：空场景 4（草原黎明、三层风的天空（云用视差 + 代码）、火山岛、云上祭典）；吊篮边框 + 燃烧器 + 绳子 1 张透明道具层；コハク纯色底姿势 4（坐在篮边、指方向、抓绳吓一跳、贴耳小声）+ 嘴 / 闭眼差分约 5。火焰、云、风线、闪电、灯笼都用代码。
- **花费**：约 14 张 ≈ $3–4；ElevenLabs 约 700 字符；Seedance 0（可选：起飞穿云的远景 1 段 64 credits，但视差就能做，多半不通过 §6.3）。
- **风险**：燃烧器一直按着会长时间加热 → 必须有占空比上限和自动降档；「头顶」这个方向耳机表现不出来，只能两耳同等（说明里写清楚）；コハク原画是旧做法，要先按 Demo10 的样子重画纯色底姿势，脸要对上。

### A2 ひやっと！おばけやしきの ちょうちんばん · Lantern Keeper of the Spooky House · 鬼屋的提灯守护者　★推荐

- **设定**：夏日祭典旁边的一间老宅「おばけやしき」，里面的鬼都很可爱、只是爱恶作剧。你手里提着会说话的灯笼妖怪 **ぼんちゃん**（提灯お化け，新角色，暖暖的大舌头笑脸）。鬼一靠近，那只耳朵就「ひやっ」地一凉——**马上把暖灯笼转过去**，鬼就「きゃー」地逃走。
- **新在哪里**：系列里第一个**反应 / 方向**游戏，冷热本身就是游戏信息（Demo10 是慢节奏解谜）。第一个夏夜场景。第 4 关画面全黑，**只靠两只耳朵的冷和声音玩**，最能说明 MoHeat Evo 是干什么的。
- **5 段（约 2:30）**
  1. **门口**（祭典的灯和太鼓在身后）：教学。一只鬼从左边慢慢来 → 左耳凉 → 点左边，灯笼转过去，鬼逃走。
  2. **走廊**：鬼从左右交替来，越来越快；要沿路捡 3 颗糖（拖到篮子里）。
  3. **和室**：纸门后面的鬼会从**背后**来（两耳一起凉）→ 长按把灯笼举高。还有「假警报」：只是穿堂风 + 风铃（凉但没有笑声），转过去会白费灯油——要分辨。
  4. **土蔵（全黑）**：画面黑掉，只剩灯笼的一点光圈。只听声音和冷热躲 6 只鬼。
  5. **鬼的女孩 ゆらり**：最后一只鬼不逃，飘到你左耳边小声说「…いっしょに、あそんでくれる？」→ 二选一（「いいよ、あそぼう」/「こわくないよ」，能说）→ 鬼们都出来了，一起看窗外的烟花。按剩下的心 / 糖给 ★1–3。
- **胜负**：3 颗心。鬼碰到你的耳朵 = 耳边一口冷气「ふぅ〜」+ 咯咯笑，掉一颗心；心掉光 → 本关重来。灯油用完（乱转太多次）同样重来。
- **互动（8）**：点左 / 右转灯笼（主操作，也可手机左右倾斜）· 长按举高灯笼（背后的鬼）· 拖动捡糖 · 说「あっちいけ〜！」= 对当前方向赶鬼（语音判定，答「こっち！」也行）· 假警报时选「風だ」/「おばけだ」· 全黑关 · 最后二选一（能说）· 结尾一句「またね」（能说）。
- **冷热（DUAL）**

  | 来源 | 位置 | 类型 |
  |---|---|---|
  | 鬼（特殊设定：鬼的身体和气息是冷的，和雪精灵同类，§0.2） | 从远到近，靠近的那只耳逐渐变凉，碰到时 1.0 脉冲 | 凉 |
  | 灯笼的火（手提约 30 cm） | 你转向哪边，哪只耳暖 0.5；举高时两耳 | 暖 |
  | ぼんちゃん的声音（灯笼本身就是火，暖） | 手边 | 暖 |
  | ゆらり的声音 | 左耳贴耳 | 凉（特殊设定，写进 README） |
  | 穿堂风（假警报） | 一侧 | 凉 |
  | 门外的夏夜 | 两耳微暖（开场、结尾） | 暖 |

  展示点：鬼的凉 → 灯笼的暖盖上去 = 同一只耳 1 s 内冷 → 冷 + 暖同时；左右交替越来越快 = 快速切换；碰到耳朵的冷气脉冲 = 强度到顶；全黑关 = 冷热当方向信息。
- **声音**：ぼんちゃん（活泼的小孩 / 吉祥物声）、ゆらり（轻飘飘的女孩）2 个新声音，各 3 个试听；约 20 句，约 900 字符。鬼的笑声、风铃、太鼓、烟花程序合成（可复用 `shared/fireworks.js`）。
- **画面分层**：空场景 4（祭典门口、走廊、和室、土蔵；全黑关用代码压暗）；鬼 3 种小精灵在一张纯色底图上（拆开做 sprite）2 张；ゆらり姿势 3（远处飘、贴耳、开心）+ 差分 3；ぼんちゃん 灯笼 1 张 + 表情 1。光圈、鬼的漂浮、闪烁、烟花用代码。
- **花费**：约 13 张 ≈ $3–3.5；ElevenLabs 试听 6 个 + 约 900 字符；Seedance 0。
- **风险**：对小孩会不会太吓人 → 鬼一律圆滚滚的可爱型、没有血和尖叫，开场先说「みんな いたずらっ子だよ」；「鬼是冷的」是特殊设定，要在台词里交代（「おばけって、ひんやりしてるんだ」）；反应时间要按设备的冷热上升速度调（冷的升温常数 0.2 s，提前 1.5–2 s 开始变凉）。

### A3 さばくの おひさまいし · The Sun Stone of the Dunes · 沙漠里的太阳石

- **设定**：沙漠和古代遗迹。向导是一只大耳朵的耳廓狐 **ルル**（新角色）。传说遗迹里藏着「太阳石」，**越靠近越暖**。
- **新在哪里**：第一个沙漠；物理上最好讲的冷热——**沙漠白天热、夜里冷**是真的。玩法是经典的「热了冷了」寻宝：哪边耳朵暖，太阳石就在那边。
- **5 段（约 2:30）**：① 白天的沙丘：太阳晒（两耳暖），找阴影躲（走进影子两耳一凉）；② 绿洲：喝水、ルル溅你一脸水（冷），装满水壶（= 步数）；③ 黄昏的遗迹入口：三条路，哪条有暖风；④ 夜里的遗迹：气温骤降（两耳凉），太阳石的暖从某一侧传来，转身 + 前进，步数有限；⑤ 找到太阳石，它在冷夜里亮起来，照亮整座遗迹；ルル贴耳说谢谢。按剩下的水 / 步数给星。
- **互动（7）**：拖动转身 · 点「前へ」走一步 · 二选一走哪条路（能说「みぎ / ひだり / まんなか」）· 长按挖沙 · 点水壶喝水（补步数）· 回答ルル的问题「あったかい？つめたい？」（能说）· 结尾二选一。
- **冷热**：太阳（两耳暖）↔ 阴影（凉）快速切换；夜气两耳凉 + 太阳石一侧暖 = 同耳冷暖同时；离太阳石越近越暖 = 强度；ルル的声音暖。
- **声音**：ルル 1 个新声音，约 16 句；风沙、驼铃程序合成。
- **画面**：空场景 4（沙丘白天、绿洲、遗迹黄昏、遗迹夜）· ルル姿势 4 + 差分 4 · 太阳石道具 1。约 13 张。
- **花费**：≈ $3–3.5；Seedance 0。
- **风险**：「热了冷了」靠逐步试探，节奏偏慢，可能不如 A2 刺激；和 Demo10「找有冷风的洞口」的玩法有一点像。

## 2. 全年龄小游戏 B（经营 / 手作 / 控温）

### B1 もりの よいち：たいやき と かきごおり · The Forest Night Market · 森林夜市：鲷鱼烧和刨冰

- **设定**：森林里只有月圆之夜才开的动物夜市。你在一个小摊打工，师傅是 **たぬきの おかみさん**（新角色）。左边是鲷鱼烧铁板，右边是刨冰机和冰块。客人是狸猫、兔子、猫头鹰的小孩。
- **新在哪里**：系列里第一个**经营 / 烹饪**游戏，有接单、限时、评分。
- **5 段（约 2:40）**：① 开店：师傅教你倒面糊、翻面（左边铁板的热）；② 第一位客人：兔子要刨冰 → 转身到右边，画圈刨冰（右边凉气），选糖浆；③ 高峰：3 位客人连着点单，左热右凉来回跑；④ 特别客人：雪猫头鹰飞到你**左耳边**小声点单（特殊设定：雪鸟的气息凉），同时左边铁板热 = 同耳冷暖；⑤ 打烊：做一份「鲷鱼烧 + 冰淇淋」给自己，两手捧在面前（前面冷暖同时）；师傅贴耳夸你，按营业额和客人笑脸给 ★1–3。
- **胜负**：翻太晚 = 烤焦（冒烟、客人皱眉）；刨冰太慢 = 化掉、客人难过地离开。
- **互动（8）**：点倒面糊 · 按住 / 放开翻面（时机条 + 滋滋声的音高）· 画圈刨冰 · 选糖浆（能说「いちご / メロン」）· 说「いらっしゃいませ！」（语音判定，开店）· 说「おまちどおさま！」（交货）· 二选一回答客人 · 结尾二选一。
- **冷热**：铁板（左前 40 cm）暖、刨冰机和冰块（右前）凉；高峰时左右 1 s 交替；猫头鹰的冷气 + 铁板 = 左耳冷暖同时；师傅的声音暖。
- **声音**：师傅 + 3–4 位客人（新声音，客人可用同一声音调不同 tag），约 25 句、约 1100 字符。
- **画面**：空场景 2（小摊正面、打烊后的夜市）· 师傅姿势 3 + 差分 3 · 客人 4 只（纯色底，sprite）· 食物道具 1–2 张（鲷鱼烧各种烤色、刨冰、糖浆）。约 14 张 ≈ $4。
- **风险**：人物多、台词多，是 4 个全年龄方案里最重的；铁板在左、刨冰在右是游戏化的摆法，要在画面里交代。

### B2 そらの かじや：ふいごで まっか！ · The Little Forge in the Sky · 天空小铁匠

- **设定**：浮空岛上的小铁匠铺。你是学徒，师傅是元气满满的女孩 **ヒバナ**（新角色）。今天的客人是一条怕热的**冰龙**，要一只能在风里响的铃铛。
- **新在哪里**：用**你的呼吸当风箱**（吹麦克风）来控温，第一次让玩家亲手把冷热强度推到顶。
- **5 段（约 2:30）**：① 冰龙降落，冷气从右边扑过来；② 鼓风：吹麦克风（或长按）让炉温升到目标区（太低 = 发暗，太高 = 火星乱飞）；③ 敲打：跟着节拍敲 8 下，火星飞向左右；④ 淬火：在时机条里把铃铛放进水桶——热蒸汽「じゅっ」一冲，随即变成凉水雾（同一只耳 1 s 内热→冷）；⑤ 冰龙用冷气把铃铛最后吹凉，挂在脖子上飞走，铃声绕你的头转一圈；评分。
- **互动（7）**：吹气 / 长按鼓风 · 节奏点击敲打 · 淬火时机 · 二选一铃铛形状（能说）· 说「できました！」（语音判定）· 冰龙的问题二选一 · 结尾一句。
- **冷热**：炉子在前（1 m，两耳暖，强度跟着你吹的力度到顶）；冰龙的气息在右（特殊设定，凉）= 左暖右凉同时；淬火的蒸汽暖 → 水雾凉；ヒバナ的声音暖。
- **画面**：空场景 2（铁匠铺、浮空岛的天空）· ヒバナ姿势 3 + 差分 3 · 冰龙 2 + 差分 1 · 铃铛 / 工具道具 1。约 12 张 ≈ $3.5。
- **风险**：吹麦克风在手机上不稳定、在安静场所不方便 → 必须有长按代替；节奏游戏要处理音频延迟。

### B3 ゆけむり どうぶつおんせん · Steamy Animal Hot Spring · 热气腾腾的动物温泉　★推荐

- **设定**：秋天枫叶满山的小温泉，客人都是动物：水豚、猴子、狐狸、企鹅。你是温泉的小帮手，向导是温泉的主人 **カピバラの ゆずじい**（新角色，慢吞吞的水豚爷爷）。每位客人想要的水温不一样：企鹅要「ぬるめ」，猴子要「あつめ」……
- **新在哪里**：**水温本身就是玩法**——玩家要靠耳朵上的冷热去「感觉」温度、把它调到刚刚好，这正是 MoHeat Evo 的卖点。经营节奏比 B1 轻、人物少；第一个秋天的全年龄场景。
- **5 段（约 2:30）**
  1. **开门**：ゆずじい教你：左边是热泉的水管（开阀 = 热蒸汽从左边冒），右边是引来的山泉冷水（开阀 = 凉水花从右边溅）。把面前的小汤池调到「ちょうどいい」。
  2. **第一位客人 · 企鹅**：要「つめたいぐらい」。往右开冷水，温度表 + 耳朵上的冷暖告诉你现在多少度；进了目标带要保持 3 秒。
  3. **猴子一家**：要「あつあつ」，但小猴子要「ぬるめ」→ 两个汤池（左热右温），左右来回调。
  4. **突然的秋雨**：冷雨落进池子（两耳凉），池水变温 → 赶快加热泉；雨里的热蒸汽 = 冷暖同时。
  5. **自己泡**：打烊后ゆずじい请你泡最后一池，你自己说「もうちょっと あつく / ぬるく」（语音判定）调到喜欢的温度；ゆずじい在旁边慢慢说「いい湯じゃのう…」。按客人满意度给 ★1–3。
- **胜负**：温度偏太多 → 客人「あちちっ！」跳出来 / 「さむいよ〜」发抖，满意度下降；时间到还没调好 → 客人走掉。
- **互动（7）**：按住左阀（加热）· 按住右阀（加冷）· 拖动木板挡雨 · 二选一回答客人（能说）· 说「いらっしゃいませ」（语音判定）· 说「もうちょっと あつく / ぬるく」（语音判定，结尾自己调）· 结尾二选一。
- **冷热（DUAL）**

  | 来源 | 位置 | 类型 |
  |---|---|---|
  | 热泉水管的蒸汽 | 左耳，开阀越久越强 | 暖 |
  | 山泉冷水的水花 | 右耳 | 凉 |
  | 面前汤池的热气（= 当前水温） | 两耳，按水温高低 | 暖 / 凉 |
  | 秋雨 | 两耳 | 凉 |
  | 秋天的山风 | 一侧，阵风 | 凉 |
  | ゆずじい / 客人的声音 | 说话的那一侧 | 暖 |

  展示点：左热右凉同时；按两个阀 = 快速切换；猴子要「あつあつ」= 强度到顶；雨中蒸汽 = 同耳冷暖同时。
- **声音**：ゆずじい（慢吞吞的爷爷声，不能和 Gen 爷爷像）+ 客人 3 种（企鹅、猴子、狐狸，可用 1–2 个声音调 tag），约 20 句、约 900 字符；水声、蒸汽、雨、枫叶程序合成。
- **画面分层**：空场景 2（白天的露天温泉、傍晚 / 雨，用调色）· ゆずじい姿势 3 + 差分 3 · 动物客人 4 种（纯色底，泡在水里只露上半身，好拆层）2 张 · 阀门 / 温度表 UI 用代码。约 12 张 ≈ $3–3.5。
- **花费**：Seedance 0。
- **风险**：玩家要在「温度表」和「耳朵的感觉」之间建立联系 → 第 1 段要教清楚；没有设备时只能看温度表（仍然能玩）；冷热两路都要长时间开，注意占空比上限。

- **Naomi 的样子**：严格照 Demo11 `scripts/make_jobs.py` 的 `LOOK` / `NAOMI`（蓝灰 + 白的长毛双色猫，额头白色倒 V、白胸毛、白手套、粉鼻子、橄榄绿眼、长尾巴），参考图 = Demo11 `media/art/naomi_*.webp` + 用户提供的真实照片（`PHOTOS`）。四脚走路，不拟人。

### N1 なつやすみ、ナオミと せんぷうき · Summer Fan Days with Naomi · 夏天，直美和电风扇　★推荐

- **设定**：盛夏的星期天，老公寓的和室，窗外蝉鸣、风铃。长毛的 Naomi 最怕热，整天在找凉快的地方。你陪她过一个下午到夜里。

- **5 段（约 2:30）**
  1. **午后的闷热**（两耳微暖）：Naomi 摊成一张猫饼躺在榻榻米上。你打开电风扇——凉风开始左↔右扫过。Naomi 抬头看风扇上的小飘带。
  2. **飘带游戏**：风扇摇头时飘带跟着飞，Naomi 伸爪去拍；你点「首振り」开 / 关、拖动风扇方向，让飘带停在她够得着的地方（3 次拍到）。
  3. **凉垫与冰瓶**：把冰过的水瓶包上毛巾放在她身边（拖动），她把脸贴上去；你也凑近——面前的冰瓶凉、她的脸颊暖，同一侧冷暖同时。
  4. **傍晚骤雨（夕立）**：天一下子暗了，雷声从远处来，雨扑进左边的窗。二选一：关窗（风停，屋里又闷）/ 留一条缝（凉风 + 雨声）。Naomi 被雷吓到，钻到你左边贴着你（左暖）。
  5. **夜里**：雨停，虫鸣，风扇开最弱。Naomi 跳上来把下巴搁在你肩上，在左耳边呼噜；风扇的凉从右边慢慢扫过。你说「おやすみ、ナオミ」→ 渐黑 → 封面。
- **互动（7）**：点开电风扇 · 拖动风扇方向 / 点首振り（飘带游戏）· 拖动冰瓶 · 二选一关窗 / 留缝 · 摸她（拖动，吓到时安抚）· 叫她的名字「ナオミ」（语音判定，她回头「にゃ？」）· 结尾说「おやすみ」（语音判定）。
- **冷热（DUAL）**

  | 来源 | 位置 | 类型 |
  |---|---|---|
  | 夏天的闷热 | 两耳 0.2–0.3（风扇吹到时减弱） | 暖 |
  | 摇头电风扇 | 左→右→左扫过，周期约 4 s | 凉 |
  | 冰瓶（包着毛巾） | 面前 / 拖到哪边哪边凉 | 凉 |
  | Naomi 的身体 | 贴着的那一侧（脸颊、肩上） | 暖 |
  | 傍晚的雨风 | 左（窗边），留缝时 | 凉 |

  展示点：风扇扫过时每只耳朵都是「闷热 + 凉风」同时（DUAL）；摇头 = 方向连续移动；开最强挡 = 强度；骤雨来时 1 s 内由闷热变凉。
- **画面分层**：空场景 2（夏天的和室白天 / 傍晚雨后夜晚，用调色出两种光）· Naomi 纯色底姿势 5（猫饼、拍飘带、贴冰瓶、吓到钻过来、肩上睡）+ 闭眼 / 张嘴差分 4 · 电风扇（会转的扇叶用代码转）+ 冰瓶道具 1–2。约 12 张 ≈ $3。
- **花费**：ElevenLabs 0（或很少）；Seedance 0（可选：Naomi 跳起来拍飘带 1 段 64 credits——这是「连续动作才成立」的那种，可能通过 §6.3，但先用静帧 + 代码试）。
- **风险**：长毛的毛边在纯色底上抠图容易出灰边（用户会放大看）→ 底色选接近榻榻米的暖色，交付前叠深色 2× 自查；电风扇对着猫要显得安全（风扇有网罩，Naomi 只拍飘带）。

### G1 なつやすみ、じいちゃんちの すいかわり · Summer at Grandpa's: Watermelon Split · 暑假，在爷爷家劈西瓜　★推荐

- **设定**：暑假回乡下。午后的蝉、在小河里冰着的西瓜、廊下的风铃和团扇、夜里稻田上的萤火虫。
- **新在哪里**：系列第一个**夏天**，和三部冬天形成对比。**蒙眼劈西瓜**是一个天然的双耳方向游戏：画面变黑，只听爷爷奶奶的指挥声从哪边来。
- **5 段（约 2:40）**
  1. **到站（中午）**：热浪（两耳暖）、蝉鸣。奶奶迎上来，把冰过的湿毛巾按在你脖子左边：「ほれ、つめたかろう？」（左凉）。二选一：「ただいま！」/「あつ〜い！」（能说）。
  2. **小河**：爷爷从河里捞西瓜，水花从右边溅过来（右凉），他得意地大笑，把冰凉的西瓜举到你右脸边「どうじゃ、つめたいじゃろ！」（右凉）。（不写「脚泡在河里很凉」：脚不在耳边。）
  3. **蒙眼劈西瓜**（画面变黑）：爷爷在西瓜那边喊「もうちょい右じゃ！」，奶奶在另一边故意说「左よ〜」（她在逗你）。你转身、走、长按蓄力挥棒。3 次机会：打中 → 「パカッ」，爷爷奶奶一起欢呼；打偏 → 爷爷大笑，再来。
  4. **廊下的黄昏**：吃西瓜、吐西瓜子比赛（点击时机，看谁吐得远——爷爷总赢）。奶奶在你左边用团扇给你扇风，一边贴耳讲爷爷年轻时的事（左耳：团扇凉 + 她的声音暖 = 同耳冷暖同时）。
  5. **夜里的萤火虫**：去稻田边，长按双手捧住一只萤火虫，再放开；回家在蚊帐里，电风扇慢慢摇头；二选一结尾（「夏休みの日記に書くね」/「明日も遊ぼう」，能说）→ 两人各一句晚安 → 渐黑 → 封面。
- **互动（8）**：二选一回答（能说）· 蒙眼时拖动转身 + 点前进 · 长按蓄力挥棒 · 吐西瓜子的时机点击 · 点团扇「もっと」让奶奶扇快一点 · 长按捧萤火虫 · 结尾二选一（能说）· 对奶奶说「ありがとう」（语音判定）。
- **冷热（DUAL）**

  | 来源 | 位置 | 类型 |
  |---|---|---|
  | 夏天午后的热 | 两耳 0.25–0.35，傍晚减弱，夜里消失 | 暖 |
  | 冰毛巾按在脖子边 | 左 | 凉 |
  | 刚从河里捞起的西瓜贴脸边 | 右 | 凉 |
  | 爷爷 / 奶奶的声音 | 他们说话的位置，贴耳最强（蒙眼时爷爷的声音 = 西瓜的方向） | 暖 |
  | 奶奶的团扇 | 左，跟着扇的节奏一下一下 | 凉 |
  | 夜里的河风 / 电风扇 | 一侧 / 左右摇头 | 凉 |

  展示点：团扇 + 贴耳说话 = 同耳冷暖同时；冰西瓜在热天里贴脸 = 1 s 内热 → 凉；蒙眼时声音和暖都在西瓜那边 = 方向；爷爷近距离大喊 = 强度。
- **画面分层**：空场景 4（乡下的公交站、小河、院子 + 廊下、夜里的稻田；黄昏用调色）· 奶奶纯色底姿势 3（迎接、扇团扇贴耳、蚊帐边晚安）+ 爷爷 3（捞西瓜举瓜、大笑、吐瓜子）+ 嘴 / 眨眼差分约 4 · 西瓜（整个 / 劈开）道具 1。萤火虫、蝉、风铃、蒙眼的黑用代码。约 13 张 ≈ $3–3.5。

### G2 あきの おにわで やきいも · Roasting Sweet Potatoes in Autumn · 秋天院子里烤红薯

- **设定**：深秋的乡下院子，柿子树、落叶、篝火、晚上的月亮。
- **新在哪里**：第一次在户外和爷爷奶奶一起**干活**；篝火是全系列最强、最真实的热源，加上秋风让「热和凉同时、风向一变就换边」成立。
- **5 段（约 2:30）**：① 摘柿子：爷爷爬梯子在上面，柿子往左 / 右掉，你接住（听声音判断方向）；② 扫落叶：拖动扫成一堆，秋风把叶子吹回来（侧面凉）；③ 篝火烤红薯：火在正面（两耳暖），风向一变烟就往你这边飘 → 左右移动躲烟（热也跟着换边）；④ 判断熟没熟：用竹签戳（软 = 熟），奶奶把烫手的红薯掰开，热气从你面前冒上来，她「ふーふー」帮你吹凉；⑤ 晚上赏月：团子、虫鸣、秋夜的凉，奶奶给你披上外套（领口暖），爷爷难得认真地讲一句话；二选一结尾。
- **互动（7）**：接柿子（点左 / 右）· 拖动扫落叶 · 左右躲烟 · 点竹签戳红薯（时机）· 二选一「おばあちゃんの分」/「おじいちゃんの分」先给谁（能说）· 说「いただきます」（语音判定）· 结尾二选一。
- **冷热**：篝火前方暖（强度随火势，到顶）+ 秋风侧面凉 = 同耳冷暖同时；风向转 = 热和烟一起换边（方向）；掰开红薯的热气 → 奶奶吹气的凉 = 快速切换；外套领口暖。
- **画面**：空场景 3（柿子树院子、篝火、月夜廊下）· 奶奶 3 + 爷爷 3 姿势 + 差分 4 · 红薯 / 柿子道具 1。约 13 张 ≈ $3–3.5。
- **风险**：「吃红薯」本身不能加热（§0.1），热只来自火和面前冒出的热气——台词要避免「吃了好暖」；篝火的持续热要有占空比上限。

### G3 ばあちゃんと はるの よもぎもち · Spring Mochi with Grandma · 和奶奶做春天的艾草麻糬

- **设定**：春天的河堤摘艾草，回家蒸糯米，和爷爷一起捣艾草年糕，最后在樱花树下野餐。
- **新在哪里**：第一个**春天**；捣年糕是一个和爷爷配合的**节奏游戏**（爷爷捶、你翻，节奏越来越快）。
- **5 段（约 2:30）**：① 河堤摘艾草（春风凉、阳光暖）；② 蒸笼开盖：热蒸汽「もわっ」从正面冲上来；③ 捣年糕：爷爷「よいしょ！」捶下，你在两次之间点击翻面（节奏越来越快；翻慢了爷爷喊「あぶなーい！」停手）；④ 奶奶教你捏团子：她在左边握着你的手（不加热），贴耳说话（暖）；⑤ 樱花树下：花瓣随风从右往左飘过（凉风），爷爷打瞌睡的鼾声，结尾二选一。
- **互动（7）**：拖动摘艾草 · 点开蒸笼 · 节奏点击（主玩法）· 说「はい！」配合节奏（麦克风音量判定，语音识别太慢）· 二选一捏成什么形状（能说）· 说「おいしい」（语音判定）· 结尾二选一。
- **冷热**：蒸笼蒸汽 = 正面强暖（瞬间到顶，再退）；春风 = 侧面凉；爷爷近距离大喊 = 暖；花瓣风扫过 = 方向。
- **画面**：空场景 3（河堤、土间厨房、樱花树）· 奶奶 3 + 爷爷 2 姿势 + 差分 4 · 臼和杵 / 年糕道具 1。约 12 张 ≈ $3。
- **风险**：捣年糕常被当成过年的活动，和 Demo29（过年）印象重叠；节奏游戏的冷热变化比 G1 / G2 少。

## 6. 要请用户决定的问题

1. 每个位置选哪一个（A1 / A2 / A3、B1 / B2 / B3、N1 / N2 / N3、G1 / G2 / G3）？可以混搭（比如把 A1 的燃烧器放进别的方案）。
2. **A2 鬼屋**：「鬼的身体是冷的」作为特殊设定（像雪精灵）可以吗？还是全年龄最好完全不要「鬼」，改选 A1 / A3？
3. **全年龄的向导角色**：A1 直接用 コハク（Demo10 的声音和造型都有，省试听）可以吗？其他方案都是新角色，要先出人物设计（几套造型给你选）。
4. **爷爷奶奶换季节的衣服**：脸、发型、体型完全不变，只把冬装换成夏装 / 秋装，可以吗？
5. **Naomi 的叫声**：能不能录一些 Naomi 本人的叫声和呼噜（手机录音就行，安静的房间、靠近一点）？有的话比合成的更像她；没有就复用 Demo11 的合成叫声。
6. 手机版要不要加**倾斜手机**控制（A2 转灯笼、A3 转身）？要用到陀螺仪权限（iPhone 会弹一次授权）。
